# PRODIGY_WD_01
# Prodigy InfoTech Web Development Internship - Task 01

## 📌 Project Overview
This repository contains the completion of **Task 1** for the **Web Development Internship** at **Prodigy InfoTech**. The objective was to create an **interactive and responsive navigation menu** that remains fixed at the top of the webpage and changes its appearance when the user scrolls or hovers over the menu items.

## 🛠️ Technologies Used
* **HTML5** (Structure)
* **CSS3** (Styling & Responsive Design)
* **JavaScript (ES6)** (Interactivity)

## ✨ Features Implemented
* Created a **fixed navigation bar** that remains visible on all pages.
* Added **hover effects** to navigation menu items.
* Changed the **navigation bar background color** when the page is scrolled.
* Implemented **smooth CSS transitions** for a modern user experience.
* Designed a **responsive layout** that works across different screen sizes.
* Organized the project with clean and maintainable code.

## 📊 Project Functionality
1. **Fixed Navigation Menu:** The navigation bar stays at the top while scrolling.
2. **Scroll Effect:** The menu changes its background color when the user scrolls down the page.
3. **Hover Animation:** Navigation items change color or style when hovered over.
4. **Responsive Design:** Ensures proper display on desktops, tablets, and mobile devices.

## 📁 Files in this Repository
* `index.html` – Structure of the webpage.
* `style.css` – Styling and responsive design.
* `script.js` – JavaScript for scroll and hover interactions.
* `README.md` – Project documentation.

## 🎯 Learning Outcomes
* Built a responsive navigation bar using HTML and CSS.
* Learned DOM manipulation with JavaScript.
* Implemented scroll event handling.
* Applied hover effects and smooth animations.
* Improved understanding of responsive web design principles.
